# SALESCOPE · 매장 판매 대시보드

업로드된 **매장판매실적.xlsx**의 2026년 7–9월 판매 내역을 분석하는 한국어 정적 대시보드입니다. 빌드나 서버 API, 외부 CDN, 인증 키가 필요 없습니다.

## 실행

저장소 루트에서 다음 명령으로 정적 HTTP 서버를 실행한 뒤, 브라우저로 서버에 접속합니다.

```sh
python3 -m http.server 8000
```

## 기능

- 기간·지역·매장·상품군 필터와 초기화, 지역에 맞춘 매장 선택
- 총매출, 알려진 판매 수량, 판매 행 수, 건당 평균 매출
- 월별·일별 매출 추이, 상품군별 매출 비중, 매장 TOP 5, 지역별 실적
- 상세 내역 검색, 날짜·수량·매출 정렬, 페이지 이동
- 현재 필터와 검색 조건에 해당하는 전체 내역을 UTF-8 BOM CSV로 다운로드
- 모바일·태블릿·데스크톱 레이아웃, 키보드 조작과 차트 텍스트 설명

## 데이터와 집계 기준

원본은 `data/sales-source.xlsx`, 브라우저용 데이터는 `data/sales.js`에 있습니다. 실행 중 업로드나 외부 전송은 없으며, GitHub 저장소에 포함된 데이터가 브라우저에 표시됩니다.

- 원본 1,017행, 13개 매장, 7개 지역, 5개 상품군
- 총매출 **515,999,400원**, 알려진 수량 **1,722개**
- 날짜(Excel 날짜·YYYYMMDD 숫자·점 구분 문자열)와 지역명 표기 통일
- ‘원’·쉼표가 포함된 문자열 매출액 10건을 숫자로 변환
- 수량 누락 5건: 수량 합계에서만 제외하고 매출과 판매 건수에는 포함. 수량을 추정하지 않음
- 요금제 빈 값은 ‘—’로 표시
- 정규화 후 날짜·지역·매장·상품군·요금제·수량·매출·담당자가 모두 같은 행 중 첫 행 이후 **18행**을 중복 의심으로 표시. 거래 ID가 없어 실제 중복이라고 단정하지 않음. 기본 집계에 포함하며 사용자가 제외 가능
- 판매 건수는 판매 행 수이며, 고객 수·영수증 수를 의미하지 않음
- 건당 평균 매출은 총매출 ÷ 판매 행 수. 실시간 데이터나 목표·전기 대비 수치는 제공하지 않음
- 상단 필터와 중복 제외 옵션은 모든 지표에 적용. 검색은 상세 내역과 CSV에만 적용
- 차트·순위의 만원 단위는 반올림하며 정확한 원 단위는 KPI·지역 실적·상세 내역·CSV에서 확인 가능

## 데이터 재생성

Python 3와 `openpyxl`이 필요합니다. 원본을 교체한 후 실행합니다. 다른 기간·스키마를 사용할 때는 기간 선택 및 화면의 데이터 안내도 함께 갱신해야 합니다.

```sh
python3 -m pip install openpyxl==3.1.5
python3 scripts/import_sales.py
```

## 검증

브라우저 검증에는 Node.js, Playwright, Chromium이 필요합니다. 브라우저 테스트는 검증용 HTTP 서버를 자동으로 시작하고 종료합니다. 테스트는 원본 엑셀에서 독립적으로 계산한 집계와 화면을 대조하며 필터·검색·정렬·페이지 이동·CSV·모바일 레이아웃을 확인합니다.

```sh
python3 tests/verify_data.py
node tests/dashboard.cjs
```
